本版内置完整日中双语剧情、离线词典和注音资源，首次启动无需连接剧情源站。剧情资源可以单独更新，也可以导入离线包；更新保留笔记和阅读进度。

- Windows x64：下载并运行 `-setup.exe`，安装器包含离线 WebView2 运行组件。
- macOS Apple Silicon：解压 `macos-arm64.zip`，将应用放入「应用程序」后打开。

基础阅读、查词、注音和笔记可以离线使用；联网更新和在线 AI 功能需要网络。

macOS 版本尚未经过 Apple 公证。首次打开若提示「Apple 无法验证」，请点击「完成」，前往「系统设置 → 隐私与安全性」，找到该应用的提示并点击「仍要打开」，按提示验证后再点击「打开」。详见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。
